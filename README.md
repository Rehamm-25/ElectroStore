# ElectroStore

A modern e-commerce front-end application built with Vue 3, simulating a real online electronics store — from browsing and filtering products, to managing a shopping cart and wishlist, all backed by a live REST API.

🔗 **Live Demo:** _(coming soon)_
🎨 **Tech Stack:** Vue 3 · Vue Router · Axios · Bootstrap 5 · REST API

## Features

- 🔍 **Smart Search & Filters** — live search across product name, brand, and category, with category filtering and multiple sorting options
- 🛒 **Full Cart Management** — add, update quantities, and remove items with real-time stock validation and subtotal calculation
- ♡ **Wishlist System** — save favorite products, synced live with the backend
- 📦 **Stock-Aware UX** — out-of-stock products are automatically disabled
- 🔔 **Centralized Notifications** — a shared toast and confirmation-modal system across the app
- 🌗 **Light & Dark Mode** — full theming system with a persistent user preference
- 📱 **Fully Responsive** — works smoothly across desktop, tablet, and mobile

## Tech Stack

- **Vue 3** (Options API)
- **Vue Router** for navigation
- **Axios** for API communication
- **Bootstrap 5** for base layout and grid
- **JSON Server** as a mock REST API backend
